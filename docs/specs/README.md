# Specs

One folder per unit of work: `NNNN-short-slug/` containing:
- `spec.md` — **what & why** (founder approves)
- `plan.md` — **how** (design, files, tests, rollout)
- `tasks.md` — ordered checklist; ticked in PRs

Copy `_template/` to start. Number from the backlog in `../plan/workstreams.md`.

Status lifecycle (first line of `spec.md`): `Draft → In review → Approved → In progress → Done`.
